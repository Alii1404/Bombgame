# PanelCreate

Windows Forms oyunu. Panel yarat düyməsi rəngli panellər əlavə edir, bombanın yerini dəyiş düyməsi bombanı başqa yerə aparır. Panel bomba ilə toqquşanda oyun bitir, səs səslənir və xal sıfırlanır.

## Açmaq
1. `PanelCreate.csproj` faylını Visual Studio 2022-də açın.
2. .NET 8 SDK quraşdırılmış olmalıdır.
3. `F5` düyməsi ilə başladın.

`Assets` qovluğundakı `bomba.png` və `bomba.wav` fayllarını silməyin.
